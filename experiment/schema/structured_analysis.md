# 结构化分析（M2 / M3 强制先输出）

在生成任何 SPDL 之前，必须按下列字段写出分析。缺字段视为该轮未完成结构化步骤。

1. **角色**：名称与发起/响应关系
2. **消息方向**：第几步、谁发给谁（可在本步骤写出内容字段；此文件对 M2/M3 可见，M0 任务看不到本 schema）
3. **长期密钥**：种类、谁持有、是否预分配
4. **临时值**：nonce / 时变参数及其新鲜性假设
5. **密码操作**：加密、签名、MAC；密钥用在哪一条消息
6. **安全目标**：准备向 Scyther 声明的 claim 类型及角色
7. **攻击者假设**：Dolev-Yao 公开网络；是否假设长期密钥不泄露
8. **版本/模型边界**：本文建模对应哪一文本；明确不覆盖哪些标准修订

然后才输出一个完整、可解析的 `.spdl`。
