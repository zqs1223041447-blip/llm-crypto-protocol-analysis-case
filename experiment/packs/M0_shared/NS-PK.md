# M0 共用短描述：NS-PK（无完整消息列表）

Needham 与 Schroeder 在 1978 年给出一类用加密做网络认证的协议，其中包含基于公钥算法的交互认证。公钥算法使用成对的加密/解密密钥，公开加密密钥不泄露解密密钥。

本任务只关心该公钥协议在**公钥已经分发完毕之后**的交互认证核心：两个主体要确认对方身份，并保护本次会话中新鲜值不被网络攻击者得到。网络攻击者可以出现在所有通信路径上：重放、改写、拼接或伪造报文，但不能打破加密，也不知道诚实主体的私钥。

文献中常把“带认证服务器分发公钥”的完整流程与“假定公钥已知后的短交互”分开讨论。本任务只要后者。不要依赖后来文献中的修复；按 1978 年公钥认证核心的原意建模。
