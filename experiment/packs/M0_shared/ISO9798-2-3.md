# M0 共用短描述：ISO/IEC 9798-2 机制 3（无完整消息列表）

ISO/IEC 9798 是实体鉴别机制族。第 2 部分使用对称加密。其中**不经过可信第三方、两轮完成相互鉴别**的机制（Basin/Cremers 称为 9798-2-3）用时变参数（时间戳、序号或随机数）防止鉴别信息被日后或重复接受。

两个实体共享长期对称密钥。发起方先送出带密码保护的鉴别令牌，响应方再送回自己的令牌。标准允许可选文本字段，并允许在某些密钥方向假设下省略对方标识。攻击者控制公开网络。本任务按 2008 年文本及 2010 年勘误所代表的“对称加密令牌”口径建模，不升级到 2019 年认证加密版。
