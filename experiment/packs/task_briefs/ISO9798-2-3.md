# 任务：ISO/IEC 9798-2 机制 3（两轮相互鉴别）

## 范围（四种方式共用）

分析 **ISO/IEC 9798-2 中不使用可信第三方、用时变参数做新鲜性的两轮相互鉴别机制**（Basin/Cremers 编号 **9798-2-3**）。

建模口径：对称加密、双向长期共享密钥、两轮、无 TTP。  
**不要**建成 2019 年版“认证加密”机制，也不要建成带 TTP 的 2-5/2-6，也不要建成三轮挑战-应答（2-4）。

结论边界必须写明：结果只覆盖所建符号模型及所对照的文本年代，不能写成 ISO/IEC 9798-2:2019 已验证。

## 输出

1. 一份可被 Scyther 解析的 SPDL（角色 A、B）。
2. 声明与相互鉴别相符的 claim（至少含 aliveness / weak agreement 或 Commit/Niagree 一类认证目标；按你的结构化分析选择，但必须可运行）。
3. 攻击者：Dolev-Yao。可选字段（Text）若建模，须说明是否参与安全目标。
